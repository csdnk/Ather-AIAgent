## 使用规则

1. **沿用 Recall 原流程与数据字典。** 本目录补充实现分层、内部交接和适配规则，不另造领域状态或全量字段字典。
2. **本地 Port 是我们消费依赖的接口。** 不要求对方增加同名 API、改字段名或换数据库，实际协议按提供方确认的版本适配。
3. **分别引用各组台账。** `A:AL-*` 指 [Recall 待确认事项](../Recall流程/运行时详细设计_V0.1/跨模块待确认事项_V0.1.md)；`B:AL-*` 指 [Remember 主设计第 7 章](../remeber流程/运行时详细设计_V0.1/记忆形成流程详细设计_V0.1.md#alignment)。同名编号不是同一事项。本目录差异编号只用于定位，不新增签收台账，也不修改原台账。
4. **设计、实现、签收、实测分开。** 新增文档不能证明外部已经支持；已有 DTO 不能证明实际 RPC 具备其全部字段和保证。
5. **不改其他组来消除冲突。** 在 Recall 适配边界保留真实事实和能力限制；无法无损适配的路径暂不启用，记录对接问题。
