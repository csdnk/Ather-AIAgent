# Remember 运行时详细设计 V0.1

本目录按照 Recall 的 `运行时详细设计_V0.1` 整理 Remember 内容，保留相同的五份主体分工：流程、数据定义、A 对接、C 对接、P2 对接。流程按 Remember 的八个阶段展开；字段、规则和外部确认分别集中维护。

建议先读[记忆形成流程详细设计](记忆形成流程详细设计_V0.1.md)，按需查[记忆形成数据定义](记忆形成数据定义_V0.1.md)。准备对接时分别使用：

- [记忆形成与召回接口对接需求](记忆形成与召回接口对接需求_V0.1.md)：B 的读取事实与 A 的 Embedding/向量机制双向交接。
- [记忆形成与调度优化接口对接需求](记忆形成与调度优化接口对接需求_V0.1.md)：Signal、消费 Ack、失效与预热边界。
- [记忆形成与 P2 接口对接需求](记忆形成与P2接口对接需求_V0.1.md)：正文/Artifact/向量的物理证明、未知查询与删除恢复。

[审查记录](审查记录_V0.1.md)列出来源差异、修订、结构/数据/引用检查及原文件保护结果。外部待确认问题统一在主设计第 7 章，避免多份表各自标为已确认。

本次仅新增本目录文件。原 Remember V2.0、Recall 模板、PRD、9.5 接口材料和其他来源均保留；W1/L1 等方案是明确标注的评审基线，外部接口、运行参数和生产结果不被文档整理代为确认。
