## 3. 关键流程的逐项推演

下表是阅读设计规则后的逻辑核对，未运行真实系统或故障注入。

| 推演范围 | 检查到的结果闭环 | 对应待实现用例 |
|---|---|---|
| 准入、幂等与正文未知 | 未授权拒绝；同键复用/冲突；正文未知只留 operation；确定后再形成主事实 | RM-T01–04 |
| 主事实与分类 | 内部未分类不对外发布；uncertain、事件性 Episodic、Semantic Candidate 分开；SessionEnd 只触发评价 | RM-T05–07 |
| 当前 Working | Redis 写失败不假成功；TTL/miss 不删除主事实；有界读取完整空/partial/故障分开 | RM-T08–09 |
| 异步交接 | Task/Outbox 先保存，重复投递与租约接管有版本屏障；内联转后台同输入、单提交者 | RM-T10–11 |
| 压缩与投影 | 跳过压缩合法；质量/字节独立；模型/空间与全部 chunk 验证后才 Ready；新 Artifact 不能偷换旧输入 | RM-T12–15 |
| 版本竞态、Signal 与历史修复 | 旧结果失权；Ack 层次分离；Outbox 缺口真实报告；历史成功不被后来损坏抹去 | RM-T16–19 |
| 使用与删除 | 未知不归零、不重复强化；业务到期即时排除；共享证据/备份/残留各有处理边界 | RM-T20–22 |
| 正式门槛 | 后台不抢前台保留资源；L2 与 L3/生产分开，P99 和压缩比无实测声明 | RM-T23–24 |
