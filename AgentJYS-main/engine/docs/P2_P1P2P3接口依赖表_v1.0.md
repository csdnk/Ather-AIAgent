| 字段 | 类型 | 说明 | P3 用途 |
|---|---|---|---|

| 字段 | 说明 |

## 4. IF-06 Tier Migrate Callback（P3→P2）

### 4.1 调用序列

```mermaid
sequenceDiagram
    participant B3 as P3-B3
    participant P2 as P2 SegmentControl
    participant P1 as P1 迁移执行

    B3->>P2: ListSegments / SegmentStats
    B3->>P2: Freeze(segment_id)
    Note over P2: 写栅栏 P2Err_SegmentFrozen
    B3->>P1: 物理迁移（P1/P2 执行边界待确认）
    alt 成功
        P1-->>B3: 完成
        B3->>P2: OnMigrateComplete(segment_id, new_block_ids)
        Note over P2: 原子换 route_epoch
    else 失败
        B3->>P2: OnMigrateFailed(segment_id, reason)
        Note over P2: 保留旧路由，解冻
    end
```

### 4.2 RPC 与 Rust trait 映射

| gRPC (SegmentControlService) | ae_kernel::SegmentControl |
|---|---|
| ListSegments | list_segments() |
| Freeze | freeze() |
| Unfreeze | unfreeze() |
| OnMigrateComplete | on_migrate_complete() |
| OnMigrateFailed | on_migrate_failed() |

### 4.3 错误码

| 场景 | P2Err_* |
|---|---|
| 未知 segment | NotFound |
| 非法状态转换 | Conflict |
| 冻结期写入 | SegmentFrozen |
