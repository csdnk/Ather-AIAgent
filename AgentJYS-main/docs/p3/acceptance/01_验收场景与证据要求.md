| 真实 Redis/Ceph/PG/Temporal 联调 | 同一测试记忆完成热命中、失效回源、Operate 升降温并发与重启恢复 | 本次未运行，不能由离线结果替代 |

上述离线证据对应[CI 复验指南](../development/11_CI检查与复验.md)的五文件测试集，2026-10-08 实现阶段合计 **118 passed**。完整结果和官方框架依据见[冷热地址读取契约](../development/17_Recall冷热地址读取契约.md)。地址读取使用真实项目逻辑，元数据和网络由隔离替身提供；不据此报告性能提升比例或 Azure 验收通过。

真实服务验收应保存测试版本、请求与记忆引用、地址前后值、实际 `path/location`、正文哈希、Redis/Ceph 调用证据和事件去重结果。故障注入限于测试数据/请求；来源原文展开是独立调用，不能以整次网页是否访问 Ceph 判断记忆热命中。

## 历史 F1 契约阶段：当时证明什么

**以下保留早期 F1 阶段以系统搭建与契约匹配为目标的范围。** 该阶段暂缓产品吞吐、延迟、压缩比、规则效果、预测收益和24h/72h时长，不纳入当时校验或下一阶段F1基座门禁。本文后续指标段落为PRD保留记录，不表示本次执行压测。健康、积压、错误和恢复记录继续建设。

本轮检查模型、Protocol、生成Schema、正反样例、HTTP映射、状态候选边、依赖方向、文档链接及需求追踪。通过仅表示这些交付物相互一致，不证明数据库事务、权限实现、恢复、模型、向量或真实调度已经工作。

[requirements.yaml](requirements.yaml)覆盖V1.2的编号小节与FR，另将指标拆为独立项；[source-manifest.yaml](source-manifest.yaml)保存来源摘要及原文定位，不需要把PRD提取全文混入交付物；[scenarios.yaml](scenarios.yaml)保存后续运行测试规格。背景小节kind=context，不能与功能验收数量混算。

| 层级 | 本轮状态 | 需要的证据 |
|---|---|---|

## 必须执行的基座故障测试

| 场景 | 注入点 | 验收断言 |
|---|---|---|
| 原子提交 | 事实后、Task后、Outbox后各中断事务 | 提交前全无，提交后全有；失败不返回已保存 |
| 提交后停投递 | 已提交Outbox，Worker未投递 | 启动扫描能推进；领域事实不回滚 |
| 消费后丢Ack | Inbox/效果/待办提交后 | 重投只有一个业务效果 |
| 双Worker争抢 | 同时领取同一任务 | 仅一个有效token；类别配额不越限 |
| 失租迟到 | 新Worker接管后释放旧Worker | 旧提交/续租失败，远端残留有对账 |
| 模型返回后退出 | 候选已算出、正式批次未提交 | 允许重算但不能重复形成正式记忆 |
| 删除竞态 | 提取、投影、最终Pack事务前后 | 以最终事务排序；失效正文不交付，旧写不复活资格 |
| Recall中断/再取 | Pack前退出；Pack后丢HTTP；再撤权 | 状态真实，不隐式重查；旧Pack不能绕过当前核验 |
| 反馈丢失 | 实际apply后丢响应 | Unknown原ID查询；无新冲突意图，实例换代不能假成功 |
| 采集故障 | Trace导出关闭/日志队列满 | 业务事实仍可查，覆盖缺失可见，队列有界 |
| 隔离恢复 | 恢复备份至新目录 | 权限、tombstone、配置和未决动作校验后才接流量 |

Toxiproxy可制造网络故障，但apply后丢响应必须由Provider定点开关保证。模拟适合失败边界；产品“真实效果”需要实际Provider重复验证。抛异常、停进程、磁盘损坏是不同故障，不互相冒充。

## 业务验收特别容易遗漏的点

- FR03文档引用绑定指定版本、权限与摘要；不是任意URL读取，受理后不用重复上传。
- FR04归档与到期、FR05独立有效冲突均保留；不能只实现active/deleted。
- FR06压缩除比例外检查数字、否定、条件、冲突和来源；原文保留，不按“成功样本子集”计算收益。
- FR08显式来源与auto都必须测试；已选来源失效不静默缩减。FR10首组超长继续后组，全超长失败；完整冲突组不拆分。
- FR11重新获取旧Pack重验当前授权、来源和版本；查询不能触发新的业务操作。
- FR12存储侧变化单独就能驱动C；read/packed/delivered不重复计热，也不能假称模型已采用。
- FR14真实目标准确可读才完成；旧副本清理可以另行待办；不能等待人工发起每项动作。
- FR15同tenant未授权Agent拒绝，显式授权共享可以使用；撤权影响后台和历史结果。
- FR17删除后新结果和旧结果再取都阻断，后台迟到结果不能复活。

## 后续指标与评价协议（当前暂缓）

[产品验收profile](../../../contracts/p3/profiles/product-acceptance.yaml)逐项保留：Working端到端P99<10ms；实际语义计算≥2000条/秒；真实内容字节压缩比≥5且质量通过；基础规则正确率100%、错误降层0；P1预测相对提升≥10%同时报百分点/成本；MVP≥24h、Final72h。

正式评价前冻结：机器规格、模型和输入规模、并发/速率、冷热/来源分布、数据授权、质量判定、失败计入方式、统计窗口与计算脚本。环境未定不是删掉指标的理由，需在对应测量前关闭。两小时负载属于预检，不纳入长稳替代证据。

恢复时间从异常发现到业务再次能按当前授权完成计算，不仅计进程拉起；RPO按实际可恢复的最新业务时间测量，备份恢复可能影响删除/动作连续性，须外部对账。不能把数据库能打开记为恢复完成。
