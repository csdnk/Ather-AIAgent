# 投影与搜索职责划分

2026-09-22 更新。B 负责建库投影、写入核验和清理；A 为 B 提供 Embedding，并为自身 Recall 执行搜索。此次完成代码职责拆分，不新增多块索引发布或全文组包业务。

## 对象及接口

| 当前归属 | 对象 / 接口 | 用途 |
|---|---|---|
| B / remember/contracts/models.py | ProjectionTarget、ProjectionRequest、ProjectionResult | 精确投影目标、写入请求、核验证据 |
| B / remember/contracts/foundation.py | ChunkProjectionRequest、ChunkProjectionResult | 新多块协议的写入与核验契约；业务接入仍待完成 |
| B / remember/contracts/ports.py | ProjectionPort.project / inspect / delete | 已有写入、查原操作、清理 |
| B / remember/contracts/ports.py | GenerationProjectionPort.project / inspect | 新多块投影接口；尚待业务接入 |
| A / recall/contracts/ports.py | VectorSearchPort.search、GenerationSearchPort.search | 基础搜索 / 新批次搜索契约；后者尚待业务接入 |
| A / recall/contracts/ports.py | EmbeddingPort.embed | Query/Passage 编码，输入输出未改变 |

对象总数仍为 118，正式接口方法仍为 68；接口组由 22 拆为 24。旧 VectorPort / GenerationVectorPort 是继承上述接口的兼容组合，不重复计数，也不注入业务服务。

## 实现与装配

- [B 的投影实现](../../../src/aether_agent_memory/remember/basic/projection.py)：SQLiteProjection、MilvusProjection、projection_target；ProjectionAccess 只提供写入、核验和删除。
- [A 的搜索实现](../../../src/aether_agent_memory/recall/basic/vector_search.py)：SQLiteVectorSearch、MilvusVectorSearch；SearchAccess 只提供 search。
- [共享连接资源](../../../src/aether_agent_memory/runtime/vector_backend.py)：数据库连接、Milvus 连接池、超时、集合准备及关闭。这里没有投影或业务搜索方法。
- [Host 组合适配器](../../../src/aether_agent_memory/runtime/flows/vector_adapters.py)：组合读写实现以复用同一后端及连接生命周期。
- [Host 装配](../../../src/aether_agent_memory/runtime/flows/host.py)：Remember.projections 接收 ProjectionAccess；Recall.vectors 及其 Sources 只接收 SearchAccess。Host.vectors 保留后端管理、已有注入和故障测试兼容用途。

这些是代码能力接口的分离，业务授权仍由当前身份与领域资格检查执行。B 和 A 不通过两个互不一致的数据副本交换向量。

## 兼容边界

旧 recall 路径下的五个投影类型改为同一对象类的导出别名；旧 SQLiteVectors、MilvusVectors 和 projection_target 导入保留为薄兼容入口。正式新代码直接从对象所有方或 Host 装配模块导入，不再把兼容位置视作业务所有权。

Schema 与目录的规范名称改为 remember.ProjectionTarget 等 B 名称；消费 Schema 文件路径或目录字符串的外部工具需切换新名称。Python 旧导入可继续使用，不代表旧目录标识仍是规范标识。

序列化字段、向量值、vector_id 算法、数据库中的 recall_vectors / milvus_projections 命名空间不变；已有库无需仅因本次代码职责调整重建索引。Embedding 实现和模型空间配置不变。

验证入口为 tests/runtime/flows/test_projection_ownership.py 及原协作门禁；正式结论见交付区本轮验收说明。真实 Milvus 服务、生产环境及新多块协议运行不在本次通过范围内。
