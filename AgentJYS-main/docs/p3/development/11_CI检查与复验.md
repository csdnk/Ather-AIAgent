## 本机静态复验

在独立 Python 3.13 环境、`AgentJYS-main` 工作目录执行。所有输出指向仓库外：

```powershell
python -m pip install --upgrade pip
python -m pip install -e . --group dev
python -B scripts/generate_proto.py
python -B -m ruff check src tests scripts
python -B -m mypy src --cache-dir <外部缓存目录>
python -B scripts/p3/generate_schemas.py --check
python -B -m pip wheel --no-deps --wheel-dir <外部wheel目录> .
```

Proto 来自保留的 `engine/proto/aether_engine.proto`，检查前生成 Python 绑定，生成文件继续 Git 忽略。Mypy 必须读取本目录的 `pyproject.toml`，否则会漏掉 Pydantic 插件和 generated/第三方边界设置。

## 冷热地址离线回归

在已安装项目及 dev 依赖的 Python 3.13 环境、`AgentJYS-main` 工作目录执行。PowerShell 示例将临时测试数据放在本机约定的项目外目录；其他开发者应改为自己的外部工作目录。

```powershell
$env:PYTHONPATH = 'src;tests'
python -X utf8 -B -m pytest `
  tests/unit/test_cache_locations.py `
  tests/unit/test_cache_address_reads.py `
  tests/unit/test_body_address_reads.py `
  tests/unit/test_recall_address_assembly.py `
  tests/unit/test_body_read_consumers.py `
  --confcutdir=tests/unit -q -p no:cacheprovider `
  --basetemp 'D:/AStore项目/codex-aether/.agent-work/workspace-support/recall-address-first/pytest-doc-example'
```

`--basetemp` 必须是专用测试临时目录：pytest 会清理其中内容，不能指向交付成果、模型或其他已有资料。上述测试使用隔离存储/网络替身，不需要云端凭据；它们执行真实地址读取、Remember、Recall 组包及正文 HTTP 路由逻辑，但不能证明真实 Redis Lua、PostgreSQL 并发隔离或 Azure 服务表现。

2026-10-08 实现阶段这五个文件合计 **118 passed**；这是该次实现验证记录，不是每次阅读或修改文档后自动重跑的结论。其余回归结果、证明范围及模块影响见[读取契约](17_Recall冷热地址读取契约.md)。CI 已纳入这五个文件；当前分支是否通过远端 CI，仍须看对应提交的 checks。

提交前独立评审补齐四个并发失效/正常删除实例后，当前五文件专项为 **122 passed**。AKS 定点测试与旧预压缩用例失败也在读取契约中单独记录，不能用选择性通过替代完整套件结论。

## 真实 Azure 回归

冷热地址读取改造的离线回归与此处真实回归分开记录，不能互相替代。候选加载、冲突补读、热命中、回源、TTL、撤权、Operate 降冷并发及 Temporal 重启续跑均需按目标环境取证。

使用 `scripts/p3/prepare_aks_test_assets.py` 在外部目录准备 BGE ONNX、分词缓存和固定版本 Linux Temporal CLI，补入团队公有 Milvus CA；用 `scripts/p3/run_aks_tests.py` 传入个人 kubeconfig、私密环境 JSON 和分配的 namespace。pytest 在 AKS 内运行，启动专用 Temporal development server，连接真实 Azure 后端。

正常返回必须包含实际执行的 JUnit、源码哈希未变、退出码 0、无 failure/error、默认零 skipped。OOM、连接失败、collect-only 或缺少 JUnit 都不能算通过。重型模型和完整回归串行执行。

默认 Azure 测试明确排除 `test_current_p2.py` 与 `test_web_gateway.py`，因为它们需要独立的外部 Rust P2/Nginx 环境；保留接口测试，单独配置并记录未运行。不能以 ignore、skip 或旧 SQLite 结果填补这个范围。

崩溃恢复继续保留真实子进程和原任务回执检查，元数据改为真实 PG；原 operation/job 身份及 Temporal deployment 绑定保持稳定。取消旧数据迁移不等于取消当前任务恢复。不要用清库、换 UUID 或固定亚秒等待代替恢复证明。
