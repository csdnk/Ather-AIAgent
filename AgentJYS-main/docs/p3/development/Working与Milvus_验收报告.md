运行环境：Windows、Python 3.13.7、Milvus Lite 3.2.1、PyMilvus 2.6.17、FastEmbed 0.8.0、ONNX Runtime 1.30.0、Temporal SDK 1.33.0。模型为 BAAI/bge-small-zh-v1.5 的 Qdrant ONNX 包，固定版本 `46fbe35fd4374a00fee7de77dfddaeb6dd6a2c59`；权重 SHA-256 `1294ea4b6331115a353d81f96b85e8c8d7fdcc284453d5b2fab5b016230aad38`。Ruff、相关 mypy、控制台入口及 `pip check` 通过。

真实数据库首轮有两项失败：测试重启后未先加载集合，以及来源过滤对照混入旧向量。已依官方接口修正测试准备，并在最终运行中通过。启动器曾发现 Windows 中文路径导致 FAISS 索引持久化失败，已采用经 ASCII 与同目录身份核验的 Windows 短路径；无可用别名时明确报错。独立评审还发现省略模型缓存路径时会采用仓库内默认目录，已用经校验的外部有效配置修复，并以省略缓存字段的配置重新通过真实验收。现有 Starlette/httpx 弃用警告仍存在，不影响本轮执行。

验收边界：

- Lite 是本地开发数据库，本次未验收生产 Standalone/集群、分布式耐久性、压力或性能 SLA；三组示例也不是统计性检索质量评测。
- HTTP 接口通过 FastAPI TestClient 验证，使用真实模型、Milvus gRPC 与 Temporal。Milvus 重启为独立操作系统进程重启；P3 重启为同一测试解释器内的完整服务关闭和重新创建。
- 本地配置固定回环监听、单服务请求工作线程和 P3 写串行；不提供 Milvus 服务层 TLS/RBAC。权限控制仍由 P3 执行，已开始的远端操作不能由随后撤权自动撤销。
- 未验证真实摘要/抽取大模型及重排模型。保持正文后端、现有默认 TTL 与 Temporal 编排；旧数据库的模型/后端绑定不得静默切换。
- 专用依赖文件固定关键运行版本并组合现有依赖；测试工具实际版本为 pytest 9.1.1、Ruff 0.16.9、mypy 2.3.1，与旧依赖文件中的工具固定版本不同，不能将其描述为整个环境逐项一致的锁文件。
