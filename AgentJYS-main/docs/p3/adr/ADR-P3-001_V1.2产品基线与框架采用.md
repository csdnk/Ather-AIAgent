# ADR-P3-001 修订：V1.2产品基线与框架采用

2026-09-20基线更新：当前按PRD V1.3开发，见[基线与租户增量](../../../contracts/p3/prd-baseline.yaml)。下文V1.2条款及批次说明保留原出处，不代表当前仍采用旧版本，也不证明V1.3增量已经实现。

状态：Proposed；日期：2026-09-19；Owner：RF；评审参与：B/A/C。本文修订外置`P3_协同开发基线_V1.0/ADR/ADR-P3-001_框架选型与工程运行架构.md`中的产品范围解释，保留可用的实现机制。没有代填团队签署或业务验收。

## 背景与决定

用户明确指定PRD V1.2。原ADR的单机Demo边界不能被解释为完整产品设计，尤其不能删去长文、压缩、归档、共享、实际调度和长稳要求。保留四人责任和先公共基座后领域接入的推进方式，产品要求按需求追踪表保留。

| 技术 / 模式 | 本版采用 | 目的 / 理由 | 替代方案与代价 | 退出 / 验证 |
|---|---|---|---|---|
| LangMem Core | B提取适配，锁定真实可用版本后接入 | 复用结构化候选和已有记忆输入；领域事实仍自管 | 全自写提取更可控但重复维护；Store Manager不满足同库原子提交 | 中文事实/否定/引述/假设质量与幂等；不达标替换适配器 |
| LlamaIndex | 参考Retriever/Fusion/Postprocessor，非完整运行平台 | 按步骤可测试，保持ContextPack契约 | 全QueryEngine还含生成；hash去重和RRF默认语义不直接等同P3 | 一基RRF、版本去重、完整冲突与预算消费者测试 |
| Controller模式 | C用Python实现当前状态Reconcile | 重复事件和反馈不明可收敛 | Go controller-runtime/CRD增加栈和集群对象负担 | Unknown原ID查询、实际读取、实例历史丢失验证 |
| SQLite UoW + Outbox/Inbox | 单机F1直接使用/按模式补齐 | 已有代码与同事务交接可验证 | PostgreSQL更适合多副本但需额外迁移 | 真实双进程CAS与崩溃测试；多副本前重评 |
| Milvus + ONNX | 复用真实检索和计算 | 已有适配与中文模型资产 | pgvector/远程Embedding可能减少或转移运维，尚无比较证据支持换型 | model_space、Query/Passage绑定、性能与投影证据 |
| Temporal | 独立学习，不接管当前Task | 理解History/Replay/Activity失败边界 | 立即采用会增加服务与在途迁移；自有Task必须限制规模 | 长流程/复杂补偿需求出现时另立替换ADR，单一权威调度者 |
| OTel/W3C/Prometheus | 标准采集，按部署接Azure体系 | 关联阶段、错误、积压，减少采集代码绑定 | 纯私有埋点绑定后端；全自建增加维护 | 导出失败主链不阻塞、标签基数/脱敏、告警闭环 |
| Azure VM → AKS | 单实例先验证；AKS后续 | 降低同时引入的变量 | 直接AKS更早练平台但不减少业务一致性工作 | PostgreSQL并发/发布/身份/存储测试后扩副本 |
| 显式资源授权 | 服务端Principal/Grant，无角色平台 | 满足私有、同tenant共享和撤权 | OpenFGA适合复杂关系但本轮非必须依赖 | 私有/共享/撤权/后台/结果再取统一测试 |

## 与原ADR不同的地方

模拟Executor仅用于工程协议与故障验证；MVP必须接实际Provider，准确内容可读后才算动作完成。已取得层级观察也不够，必须核对原动作身份、实例、版本和读取证据。基础调度由两侧轨迹自动触发，不新增用户调度入口。

不建设四视图管理平台、RBAC/身份平台或专用审计平台；用状态API、受控维护命令、日志与现有监测工具。必要操作记录仍保留，不因“不建平台”省掉追溯。

Schema从`p3-demo/1`演进为独立`p3/1`，增加产品需要的归档、任务/应用范围、共享Grant、文档、Artifact、冲突组、来源选择、原结果再取和real执行证据。HTTP v1保留，本轮不做运行迁移。

## 接受的风险与约束

2026-09-19用户补充：当前优先把系统搭建起来，性能和效果指标暂不考虑。相应PRD目标保留但延后评价，不作为本轮契约或F1实现的放行条件；运行健康监测及一致性、授权、恢复边界继续保留。

SQLite单机写并发、远端副作用不确定、模型质量与成本都需实测；框架不能自动保证exactly-once、授权或删除。基座参数是初始工程配置，不能用5秒Recall或低并发设置替代PRD独立的性能验收。生产备份恢复不能复活已删内容，需要连续证据与复测。

性能/算法质量/共享保留细则按PRD14.2在相应验收前闭合。版本、许可证、依赖与模型摘要纳入交付；引用设计思想不等于复制源码，复制第三方实现须保留适用许可声明。
