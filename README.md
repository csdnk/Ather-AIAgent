## GitHub 统一维护

本项目统一关联 [csdnk/Ather-AIAgent](https://github.com/csdnk/Ather-AIAgent)。Git 管理范围为当前目录，包含交付成果、项目资料、框架研读项目和 `AgentJYS-main` 业务代码；本地环境、缓存、凭证和 Office 临时锁文件不提交。

开发、安装及测试命令仍从 `AgentJYS-main/` 执行。GitHub 实际执行的工作流位于根目录 `.github/workflows/`，已适配代码子目录；代码目录内的同名工作流保留为独立代码包的配置参考，修改检查规则时应同步两处。

历史代码提交保留在同一 Git 历史中，旧版本代码位于当时的仓库根目录，统一维护后的代码位于 `AgentJYS-main/`。
