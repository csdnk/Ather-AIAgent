# P3 Azure 服务身份与调用说明

2026-10-03 已生成实际服务账号，并在 `aether-p3-production` 命名空间创建 `p3-service-identities` Secret。服务器配置只包含 SHA-256 凭据摘要，Secret 读回与本机身份配置逐字节一致。正式 P3 进程尚未启动，外部入口和上线验收仍在实施。

这些账号用于调用方后端访问 P3 API。当前不依赖企业 SSO，因此无需填写 issuer、audience 或 JWKS。将来接入用户登录时，再配置对应身份提供方；本次不把服务账号描述为个人登录系统。

## 已创建的账号

| 账号 | 权限 | 用途 |
|---|---|---|
| `p3_application` | 记忆读取、写入、纠正、删除、历史 | 调用方应用后端 |
| `p3_readonly` | 记忆读取、历史 | 只读集成 |
| `p3_operator` | 记忆读取、历史、诊断、恢复、配置 | 维护操作；生产 `maintenance_principals` 应仅列此账号 |

三个账号使用不同的 48 字节随机值生成令牌，初始 `auth_epoch=1`、身份配置 `revision=1`。租户为 `aether`，应用为 `p3`，共享的业务 `user_id=backend`、`agent_id=aether`。共享业务范围使只读账号能读应用账号写入的记忆，但不能写入；不会自动获得其他租户或用户范围。

这是一个租户的服务接入配置。接入另一个客户时，应配置其独立租户和凭据。不能通过请求里的 tenant 或 user 字段扩大令牌的权限范围。

## 凭据文件

实际令牌保存在本机私密目录 `P3_Azure生产身份_本机私密/service-credentials.json`，摘要配置为同目录的 `identities.yaml`。该目录已设置仅当前 Windows 用户与 SYSTEM 访问，并通过本机 Git 排除规则验证；没有将明文令牌写入聊天或上传到服务器身份 Secret。

用户此前填写的 `P3_真实模型与生产身份_本机私密配置.yaml` 保持原内容。本次没有覆盖其中模型配置。

调用程序从私密文件或自己的 Secret 管理方式加载令牌，放入 HTTP `Authorization: Bearer` 请求头。令牌只交给对应后端调用方，维护账号单独保管。服务正式就绪后，先调用 `/p3/auth/me` 验证返回的账号和范围，再执行业务；启动前或依赖不可用时 `/p3/readyz` 返回 503。

正式入口和最终镜像摘要以最终部署验收记录为准。目前不把旧演示入口当作这三个账号的服务地址。

## 轮换与撤销

身份配置采用完整替换，不能只上传要变更的一个账号而丢掉其他账号。

轮换某个账号时，生成新的随机令牌，替换该账号的 `credential_sha256`，把其 `auth_epoch` 增加 1，同时把整个配置的 `revision` 增加 1。完整配置通过生产 Secret 发布后，运行实例自动重新读取配置；挂载应使用整个 Secret 目录，不能使用阻止更新的 `subPath` 挂载。客户端切换到新令牌后，验证旧令牌被拒绝。

撤销账号时，从完整 `identities` 列表移除该账号并增加配置 `revision`。服务保留撤销记录，旧配置不能恢复旧授权。将来恢复同名账号，需要新的随机令牌、比历史更高的 `auth_epoch` 和配置 `revision`；不得重置为 1。

发布新配置前保存当前配置和新令牌的私密副本，并核对服务器 Secret 的当前版本。若发布请求的响应丢失，先读回原 Secret 核对，不重新生成另一组令牌。已经轮换或撤销的身份不能通过回滚旧配置恢复；应用镜像回滚时继续使用最新身份配置。

正式服务上线后仍需完成 Secret 自动刷新、HTTP 旧令牌失效、多个实例读取相同版本，以及维护操作权限的端到端验收。本轮组件结果不能代替这些项目。

## 已完成的真实验证（AS-36）

AKS 验证 Pod 连接真实 Azure PostgreSQL，使用测试专用 schema 和独立随机令牌，2 项测试通过（0.71 秒）。测试直接使用已有身份实现，没有替换数据库或伪造鉴权结果。

- 应用账号可写、只读账号仅可读；跨租户资源拒绝；`alice/eve/bootstrap_admin/local_admin` 等旧演示凭据拒绝。
- PostgreSQL 只保存摘要；新建连接后原令牌可正确识别。
- 轮换后旧令牌拒绝，已取到旧上下文的请求在提交时重新检查权限并回滚。
- 旧配置版本不能恢复旧密钥；撤销后新连接仍拒绝旧令牌，同一历史 epoch 不能复活账号。

实际生产凭据单独生成并保存，测试没有轮换或撤销生产 Secret 中的账号。服务器 Secret 已逐字节读回核对，但尚未由正式 P3 进程加载。
