# 若依云端使用说明

## 登录入口

- [若依管理后台](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/ruoyi/)
- [Agent 对话与记忆](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/ruoyi-agent/)
- [本机登录凭据](若依云端账号_仅本机.private.txt)：包含 6 个可登录账号的密码，仅当前 Windows 用户可读，已排除 Git。不要将此文件随报告分享。
- [实现分支](https://github.com/csdnk/Ather-AIAgent/tree/codex/ruoyi-platform-20261006)

登录只需要用户名和密码，不填写租户。平台会从已验证的身份确定租户和权限。后台与 Agent 使用同一账号体系；两个入口分别建立自己的登录会话，后台登录不会自动建立 Agent 会话。

| 用户名 | 角色 | 适合入口 |
|---|---|---|
| aetherplatform | 平台管理员 | 管理后台，查看全局运行情况与租户 |
| aetheradmina | 租户 A 管理员 | 管理后台，管理本租户 |
| aetheradminb | 租户 B 管理员 | 管理后台，管理本租户 |
| aetherusera | 租户 A 用户 | Agent 对话与记忆 |
| aetherusera2 | 租户 A 第二用户 | Agent 对话与记忆 |
| aetheruserb | 租户 B 用户 | Agent 对话与记忆 |

另两个种子账号用于禁用用户、禁用租户的拒绝验证，不作为日常可登录账号。临时验收租户已经停用。

## 查看和使用后台

平台管理员登录后，在系统管理中查看租户、用户、角色和权限，在 Aether 管理菜单中进入运行总览、请求、任务、记忆回执、告警、配置、备份、用量、资源、支持、审计、命令、规则和配额。

建议先用平台管理员查看运行总览及任务，然后在 Agent 中用 `aetherusera` 完成一次对话，再回后台查看请求和任务记录。记忆保存是后台执行过程，应分别查看对话完成、记忆保存回执和实际召回结果。

租户管理员的可见范围和操作受服务端权限限制。新建租户时使用业务租户套餐；新用户由若依创建并映射到 Python 业务身份，不需要再到 Budibase 或 Keycloak 建账号。

平台管理员管理某个业务租户的用户时，先在后台顶部的管理范围下拉框选择该租户，例如 `Aether Tenant A`，再进入“系统管理 → 用户管理”。查找停用账号时，将状态选择为“禁用”或清空状态条件，按用户名搜索，再打开该行的状态开关并确认启用。清除顶部租户选择会回到平台自身的管理范围。这个管理范围切换仅向具有跨租户权限的管理员提供，登录时仍不要求填写租户。

任务或运维操作返回“已受理”不代表执行已经完成。发生超时或未知状态时，使用页面里的“查询原命令结果”，保留原命令编号；不要通过更换编号重复提交相同写操作。

配置页管理 P3 配置快照及其版本。页面会读出当前版本；过期版本不能覆盖当前快照。此操作不等同于热更新模型地址、存储连接或容器配置。

备份页执行平台 PostgreSQL 备份。恢复演练仅允许指定的隔离空数据库，不支持覆盖线上业务库；演练数据库非空时会拒绝重复恢复。

## 运行与访问边界

服务运行在 Azure AKS，应用镜像已经推送到 ACR；用户访问公网 HTTPS 地址不依赖本机代理或本机 Python 服务。

正式 Agent 路径是 `/ruoyi-agent/`。旧 `/agent/` 地址在最终切换后跳转到对应新路径，旧 Budibase 与身份页面转向若依后台。原 Temporal UI、P3 文档和 OpenAPI 公网入口关闭，任务通过若依工作台查看，Temporal 引擎继续在内部运行。

本次是单副本集成部署。平台重启后需要重新登录，业务数据保留；不应将会话中断当成业务数据丢失。高可用、完整灾备、长稳和负载结果请以验收报告中的明确范围为准。

账号密码在最终日志修复后统一轮换，旧访问和刷新令牌已撤销。日常使用如修改账号密码，本机凭据文件不会自动更新。
