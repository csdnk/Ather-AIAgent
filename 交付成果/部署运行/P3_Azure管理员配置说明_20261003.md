# P3 Azure 管理员配置

当前实现已通过真实 PG、Redis、Milvus、Ceph、BGE 和模型的完整记忆业务测试。正式部署还有两项已实际验证的 Azure 配置/权限缺口，需要资源管理员处理。

| 项目 | 实际结果 | 所需操作 |
|---|---|---|
| Temporal PostgreSQL 扩展 | 官方 1.32.0 初始化到 visibility 1.2 时，Azure 拒绝 `btree_gin`，报 `not allow-listed`；`azure.extensions` 当前为空 | 在现有 `postgresp3` 的 `azure.extensions` 加入 `BTREE_GIN`，保留其他允许项 |
| 镜像发布 | 当前账号与 ACR 发布相关的权限只有 AcrPull，实际本机推送返回 `insufficient_scope`；当前有效权限也不含 ACR Tasks 构建操作 | 由已有合法发布身份/CI 发布；或由管理员在现有 `aetherp3acr` 范围授予当前发布账号 AcrPush，用于本机已验证镜像的发布 |

已准备[管理员脚本](P3_Azure管理员配置_20261003.ps1)。请在具备相应权限的 Azure 登录会话执行：

```powershell
# 默认只检查，不修改。
& .\P3_Azure管理员配置_20261003.ps1

# 若由已有发布身份/CI 发布，只处理 Temporal 扩展。
& .\P3_Azure管理员配置_20261003.ps1 -Action EnableTemporalExtension

# 确认需要给当前账号本机推送权限时，再执行这一项。
& .\P3_Azure管理员配置_20261003.ps1 -Action GrantImagePush

# 两项均由该管理员处理时，可使用 All。
& .\P3_Azure管理员配置_20261003.ps1 -Action All
```

目标订阅是 `c50c3827-2bb7-43bd-a2e9-76137e2a180e`，资源组为 `aetherstore-p3`。AcrPush 默认授给当前实施账号对象 ID `421c967e-e6fc-43c0-bf73-3b54b688e4bd`，作用域限定为该 ACR。脚本不会授予 Owner 或 Contributor，不会创建数据库、删除数据或重启数据库。2026-10-03 查询显示扩展参数为动态参数；执行后仍会验证实际允许列表。

完成后，实施方会在已有 `agent` 数据库的专用 schema 安装扩展，按官方 schema 版本从当前进度续跑。主 schema 已到 1.19，visibility 已到 1.1；不会重置已完成结构或重新初始化已有版本。运行时数据库账号已单独创建，没有超级用户、建库或建角色权限。

这些管理员操作本身不代表 P3 已上线。正式 Temporal、访问凭据、P4 恢复、完整回归、镜像发布、备份恢复和持续运行验收继续单独记录。
