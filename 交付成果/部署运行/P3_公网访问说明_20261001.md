# P3 公网访问

**已配置并验证：[打开 P3 监测网页](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com)。** 浏览器直接访问即可，无需 Azure CLI、kubectl 或本机端口转发。

## 如何连接

1. 打开上面的 HTTPS 网址。
2. 在网页选择“配置连接”，输入已获授权的 P3 令牌。
3. 连接后查看服务健康、任务、异常及调用链路。令牌仅在当前页面内存中使用；刷新或关闭页面后需要重新输入。

当前电脑可执行以下成品脚本，自动复制已有令牌到剪贴板并打开网页，然后在凭据框按 Ctrl+V：

```powershell
& 'E:/projects/codex/aether/交付成果/部署运行/打开P3公网网页.ps1'
```

脚本运行后可以关闭 PowerShell 窗口。团队其他电脑直接打开相同网址，使用各自获得的授权凭据。该脚本只适用于当前电脑保存的令牌；网址本身不提供权限。当前测试令牌具备部署管理员权限，发放对象应按测试授权确定，后续个人账号与统一登录由 P4 接入。

## 访问范围

| 项目 | 当前入口 |
|---|---|
| Web 与 P3 API | HTTPS 域名；API 路径仍为 `/p3/...` |
| 公网 IP | `4.194.21.201`；浏览器使用域名以匹配证书 |
| HTTP | 自动 308 跳转到同一域名的 HTTPS |
| API 文档 | 继续使用本机转发 `http://127.0.0.1:18080/docs` |
| Temporal UI | 继续使用本机转发 `http://127.0.0.1:8233` |
| 配置、维护、备份与恢复演练接口 | 公网代理返回 404；经受控内部入口管理 |

无令牌及错误令牌访问业务/监测数据时返回 401。服务存活与就绪接口可公开读取。当前证书有效至北京时间 2026-12-30 15:36:33；Caddy 已启用自动续期，未来实际续期尚未到期验证。

## 已验证与运行边界

2026-10-01 实测 DNS、负载均衡与公网 IP 一致，公共可信 HTTPS、网页静态资源、认证拒绝/允许及全部监测读取入口通过。原 P3/Web/Temporal/Temporal UI Pod 未被此次部署重启，原业务数据卷保留。[公网接入验证报告](../测试与验收/P3_公网HTTPS接入验证_20261001.md)列出证据与重要失败处理。

入口链路为公网负载均衡 → 独立 Caddy → 现有 Web → P3。新增一个静态公网 IP、一个代理 Pod 和 1Gi 证书数据卷，使用现有 AKS；这些 Azure 资源会产生费用。当前仍是单实例测试部署，真实模型/P2、生产身份、长稳和灾备的验收范围见[部署进度](P3_AKS部署进度_20261001.md)。

日常关闭电脑或 PowerShell 不影响公网服务。需要关闭公网时由维护人员撤销独立 `public-web` Service，并确认 Azure 负载均衡规则消失；保留 `p3-data`、`temporal-data` 与命名空间。访问方案与回退见[接入方案与执行计划](P3_公网HTTPS接入方案与执行计划_20261001.md)。
