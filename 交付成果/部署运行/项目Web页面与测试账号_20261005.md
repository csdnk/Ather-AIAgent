# 项目 Web 页面与测试账号

更新时间：2026-10-05。当前日常入口为 Azure HTTPS；不需要运行本机测试环境或端口转发。旧 `18080/docs`、旧 Azure 监测 Web 不再列为当前入口。

## 业务、设计与运行页面

| 页面 | 访问地址 | 登录与用途 |
|---|---|---|
| Agent 用户平台 | [打开 Agent](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/agent/) | `user_a`、`user_a2`、`user_b`；对话、历史会话、重命名、文本附件 |
| 我的记忆 | [进入 Agent 后点击“我的记忆”](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/agent/) | 沿用 Agent 登录；查看、保存、导入、检索及维护个人记忆 |
| 来源与记忆 | [进入 Agent 对话](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/agent/) | 对话内查看召回内容、来源原文与保存回执 |
| Budibase 管理后台 | [打开管理后台](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/app/default%20workspace/aether-admin) | 点击 **Log in with Aether**；平台管理员或租户管理员 |
| 用户管理／租户目录／变更记录 | 管理后台侧栏 | 按当前登录账号的角色与租户返回数据 |
| **Budibase 可视化设计器（Builder）** | [打开 Builder](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/builder) | **`builder@aether-lab.invalid`**，使用邮箱密码登录；构建、编辑、发布后台 UI |
| Temporal 运行页面 | [查看 Agent 工作流](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/temporal/namespaces/aether-agent-20261005/workflows) | 先以 **`platform_admin`** 登录管理后台，再在同一浏览器打开；只读，无需 P3 令牌 |
| **P3 API 接口文档** | [打开接口文档](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/docs) / [OpenAPI JSON](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/openapi.json) | 先以 `platform_admin` 登录管理后台，再在同一浏览器查看；文档不提供在线执行接口 |
| Keycloak 认证服务 | [Realm 地址](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/identity/realms/aether-lab) | 日常从业务页面登录；这是认证服务地址，外部未开放 Keycloak 管理控制台 |

公网首页 [打开项目](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/) 自动进入 Agent。P3 接口文档已通过管理员认证发布；实际 P3 API 仍保留集群内部访问限制。

## 测试账号

| 账号 | 身份 | 入口 |
|---|---|---|
| `user_a` | 林晓，青禾普通用户 | Agent |
| `user_a2` | 陈墨，青禾普通用户 | Agent |
| `user_b` | 周宁，远帆普通用户 | Agent |
| `platform_admin` | 平台管理员 | 管理后台、Temporal |
| `tenant_admin_a` | 青禾租户管理员 | 管理后台 |
| `tenant_admin_b` | 远帆租户管理员 | 管理后台 |
| `disabled_user_a` | 已停用用户 | 拒绝访问验证 |
| `user_c` | 所属租户已停用 | 拒绝访问验证 |
| `builder@aether-lab.invalid` | Budibase 设计器管理员 | Builder 邮箱密码表单 |

密码沿用迁移前值，集中保存在项目负责人另行提供的私有密码清单。该文件包含明文测试密码；本入口说明不重复保存密码。

普通用户和管理员不能互相替代。Agent 与后台可以同时登录；比较不同后台身份或使用 Builder 时建议独立浏览器会话。用户无需填写或选择租户。Agent 登录会话保存在内存中，服务重启或会话到期后需重新登录，已保存的对话仍在数据库中。
