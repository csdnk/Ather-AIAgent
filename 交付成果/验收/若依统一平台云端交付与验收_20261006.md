## 重要限制

本次为可运行的单副本云端集成版本，未完成生产高可用、完整灾备、长时间稳定性与负载验收。BFF 会话存在内存中，应用重启后需要重新登录，业务数据持久化与会话持久化不能混为一谈。

前端生产构建与全仓类型检查分别报告；上游完整 vue-tsc 仍有自动导入及类型错误，不能声称全仓类型检查通过。自动化浏览器在当前工具环境受到限制，已完成的 API 与公网资产检查不等于登录后的视觉验收。

未配置的短信、邮件、微信及第三方登录不作为已交付的联通能力；相关示例凭据已移除，未配置的第三方服务明确拒绝执行。统一若依账号与企业级身份联邦不是同一项验收结论。

配置命令超时后的自动恢复以当前活动快照为证据；如果目标版本已被下一版本覆盖，或进程在保存目标证据之前退出，原命令可能持续未知。系统不会为了收口而重复执行写入。

## 回退原则

先停止新 P3 worker，待其完全退出后才能恢复旧 worker；始终保持原状态绑定，避免双 worker 占用同一执行域。上线后的新增平台数据必须保留；旧数据库快照不能直接覆盖新写入。需要受控逆向增量或经兼容性验证的共享数据库切回。原始私有配置、快照与日志保存在项目外受限工作区，不随本报告分享。

原始执行记录和私有配置在项目外受限工作区保存；报告保留证据编号、关键失败修复和限制，需要追溯时可按编号取证。

后续协调：完成上述验收后，收到独立聊天恢复旧系统的协调消息。本任务已冻结所有旧服务、配置、持久卷和网关操作；后续旧系统恢复不属于本报告的执行记录。当前若依 P3 仍共享原 PVC、数据库 schema、存储 namespace 与 Temporal 执行绑定，恢复旧 P3 前必须完成隔离或受控单 worker 切换，不能仅复制数据卷后同时启动。
