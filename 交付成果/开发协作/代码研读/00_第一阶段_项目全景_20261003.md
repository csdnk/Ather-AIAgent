## 1. 先建立一个准确的认识

这个工作区以 **P3 Agent 持久记忆服务** 为中心，同时保存了 Web 界面、P4 模拟调用方、Rust P2 存储引擎，以及大量需求、设计、验收和历史资料。

P3 的两个主要业务入口是：

- **Remember**：接收对话、任务内容或文档，保存可追溯的记忆，并安排后续处理。
- **Recall**：按当前身份、查询和范围寻找可用记忆，读取正文，组织返回给上层 Agent 的上下文。

**Operate** 负责内部的访问热度、缓存准备、周期处理与恢复。它是系统的核心内部能力，不能简单理解成与 Remember、Recall 完全对称的第三个公开业务按钮。

当前统一服务的装配集中在 `runtime/flows/`；业务分别在 `remember/`、`recall/`、`operate/`；公共事务、身份、任务和事件在 `runtime/foundation/`；持久工作流执行在 `runtime/temporal/`。

证据：[Service.initialize](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/application.py:78)、[ThreeFlows](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/host.py:45)、[公开 Remember/Recall 路由](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/http.py:361)。

## 3. 项目真正的入口点

### 3.1 当前统一 P3 后端

在业务目录下，推荐入口命令的形状是：

```powershell
python -m aether_agent_memory serve --config <部署目录>/service.yaml
```

这里只解释命令，没有在本轮执行。安装后 `aether-p3 serve --config ...` 会进入同一个 `main()`。

入口证据：[pyproject.toml 命令注册](E:/projects/codex/aether/AgentJYS-main/pyproject.toml:118)、[__main__.py](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/__main__.py:3)、[cli.main](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/cli.py:87)、[Dockerfile.p3](E:/projects/codex/aether/AgentJYS-main/Dockerfile.p3:13)。

**第一段项目代码在哪里执行？** Python 的 `-m` 机制先加载包，执行 `__init__.py` 的顶层定义，再执行 `__main__.py`。后者导入 `cli.main`，在主模块分支中执行 `raise SystemExit(main())`。严格说包初始化先发生；业务启动的显式入口是 `cli.main()`。`__init__.py` 提供惰性兼容导出，不会仅因导入当前 flow 模块就启动旧服务。

### 3.2 按实际调用顺序理解初始化

| 顺序 | 代码位置与调用 | 这一步产生什么 |
|---|---|---|
| 1 | `__main__.py → cli.main()` | 解析 `init`、`check-config` 或 `serve`；它们是分支，不是每次启动依次执行的三个步骤 |
| 2 | `cli.main → ServiceConfiguration.load()` | 读取 YAML；以配置文件所在目录解析相关相对路径；校验配置模型 |
| 3 | `cli.main → uvicorn.run(..., factory=True, workers=1)` | 记录配置路径，要求 Uvicorn 加载工厂函数；这条 CLI 配置一个服务进程 |
| 4 | Uvicorn 调用 `application.application()` | 再读取明确的配置文件，然后 `Service(config).app()` |
| 5 | `Service.__init__()` | 获取数据目录锁，必要时检查既有执行后端绑定，再调用 `initialize()` |
| 6 | `Service.initialize()` | 检查身份配置和选定后端所需环境；按配置创建模型、Ceph/P2、Redis 等 provider |
| 7 | `remember.local.create_runtime() → ThreeFlows(...)` | 创建 Foundation、Embedding、Vectors、RememberPipeline、Recall 和 Operate 等对象 |
| 8 | `RememberFactory.attach() → ThreeFlows.enable_generation_recall()` | 把候选资格、正文和最终复核边界连入 Recall；最终 `runtime.recall` 是 GenerationRecall |
| 9 | `Service.initialize()` 后半段 | 安装 Documents、分层正文缓存、身份/JWT、Trace、缓存维护；创建 TemporalService，注册业务阶段和探针 |
| 10 | `Service.app() → http.create_app() → routes.attach()` | 创建 FastAPI 对象，注册主路由、Remember 扩展路由及目录/文档路由；保存对 Service/Runtime 的引用 |
| 11 | FastAPI lifespan 调用 `TemporalService.start()` | 刷新身份，尝试连接独立 Temporal Server，启动 SDK Workers、发送待投递意图、启动/接入周期工作流 |
| 12 | `TemporalService.coordinate()` | 持续刷新连接/身份和待投递工作；HTTP 是否可接收业务请求还取决于 readiness |

主要定位：[配置加载](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/config.py:263)、[Uvicorn 调用](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/cli.py:141)、[Service](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/application.py:41)、[create_runtime](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/remember/local.py:111)、[Factory.attach](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/remember/local.py:68)、[GenerationRecall 装配](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/host.py:314)、[HTTP lifespan](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/http.py:79)、[TemporalService.connect](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/temporal/service.py:139)、[TemporalService.start](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/temporal/service.py:231)。

## 4. 当前架构关系图

下图表达实际装配关系；横向分支不是每个请求必须按顺序经过的步骤。

```text
调用方
├── 上层 Agent / 直接 HTTP 客户端
├── Web 监测页 ───────────────────────────────┐
└── Web 演示页 → P4 Simulator → P3 HTTP ──────┤
                                             ▼
P3 API：runtime/flows/http.py + routes.py + remember/http.py
  认证/可信上下文、请求解析、ready 门禁、结果与运行查询
  │
  ├── 只读/管理查询 → 相应业务或 Foundation 查询
  │
  └── Remember / Recall 执行请求
       ↓
     TemporalService：准入、输入保存、执行账本、等待/查询结果
       ↓ IntentBridge / TemporalGateway
     独立 Temporal Server ←→ 同一 P3 进程内的 SDK Workers
       ↓ P3TaskWorkflow / Activities / StageRegistry
       ├── RememberPipeline + SaveStages / 后台阶段
       ├── GenerationRecall + 候选资格/正文/上下文组装
       └── ContinuousOperate + 缓存维护
               │
               ├── 公共底座 Foundation
               │    ├── Identity / Tasks / Events / Monitoring
               │    └── UnitOfWork → SQLite 或 PostgreSQL
               ├── 正文 Bodies → 本地 SQLiteP2 / P2 gRPC / Ceph RGW
               ├── 向量 → 基础存储适配 或 Milvus
               ├── Embedding → native 模型 或显式 lexical 本地基线
               ├── 可配置的模型 API
               ├── 文件缓存 / 可配置的 Redis 正文缓存
               └── 可配置的 Keycloak / OTLP 接入
```

**读图时最关键的一点**：Temporal Server 在服务进程外；实现业务活动的 SDK Workers 当前由同一个 P3 进程启动。既不能把它画成“Temporal Server 直接保存全部业务数据”，也不能仅凭接入 Temporal 就判断整个产品已分布式部署。

存储分支是按配置选择的，不能从代码中确定你当前线上实例启用了哪一组。当前代码已含 PostgreSQL 与 Ceph 接入，不能继续按旧版本认定它只支持 SQLite。选择逻辑见 [Service.initialize](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/application.py:78)、[Foundation 的后端选择](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/foundation/host.py:40)、[向量后端选择](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/host.py:118)。

`SQLiteVectors` / `SQLiteGenerationSearch` 的类名还不能单独证明底层连接一定是 SQLite：当前代码会把 Foundation 的 `uow` 注入它们，Foundation 也可以选择 PostgreSQL。后续第六阶段会沿实际配置和对象绑定区分“名字”和“实际后端”。

## 5. 第一个核心业务流程是什么

严格地说，**代码没有规定第一条用户请求必须是什么**。服务启动不会自动创建一条用户记忆；Temporal 连接成功后会启动/接入周期工作流，是否有待处理任务由已有状态决定。

为了学习，我们选“第一次保存一条对话记忆”为第一个业务例子：用户提交“我喝咖啡不加糖”。此处只建立路标，完整输入、输出、状态和异常追踪留到第三阶段。

```text
POST /p3/remember
  ↓ http.remember(request, response, ctx)
TemporalService.execute(ctx, "remember.save", payload, headers)
  ↓ accept → InputStore.persist → CommandAdmission.accept
执行账本/投递意图 → IntentBridge → Temporal Server
  ↓ SDK Worker 中的 P3TaskWorkflow / Activities.execute_step
StageRegistry 找到 remember.save 对应的 SaveStages
  ↓ prepare → persist → commit → admit_cache
RememberPipeline.prepare_save / commit_save + Bodies.persist 等
  ↓
业务记录、正文、后续任务；保存结果引用
  ↓ TemporalService.await_result / result
RememberReceipt → HTTP 调用方
```

关键定位：[HTTP remember](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/flows/http.py:361)、[TemporalService.execute](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/temporal/service.py:381)、[accept](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/temporal/service.py:287)、[阶段注册](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/runtime/temporal/ingress.py:201)、[SaveStages](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/remember/basic/temporal_stages.py:74)、[prepare_save](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/remember/basic/pipeline.py:473)、[commit_save](E:/projects/codex/aether/AgentJYS-main/src/aether_agent_memory/remember/basic/pipeline.py:558)。

如果 HTTP 等待预算内还没有最终结果，执行代码会抛出带任务编号的 PendingOperationError；不能假设所有请求总是立刻得到最终回执。另一个需先记住的边界是：**保存完成，不等于后续抽取、长期化和向量索引都完成**。
