# PRD V1.3 基线切换与增量

日期：2026-09-20。依据用户“PRD按照最新的来”，当前开发、ADR与Mock评审统一采用[《AetherBrain_P3_PRD_租户补全版_V1.3》](../PRD版本/AetherBrain_P3_PRD_租户补全版_V1.3.docx)，文档日期2026-09-19。

这是开发需求基线切换，不代表甲方已经批准全部ADR，也不代表新增功能已实现或通过验收。PRD原件保持不变，原文状态仍为产品评审稿。

## 相对V1.2的实际变化

已对照两份Word正文。V1.3主要在3.3、5.4、FR15、8.2、9.3、11、12.8和14.2补全租户与身份规则，其余产品范围及阶段计划沿用V1.2。

| 新增或明确的要求 | 责任 | 当前工作 |
|---|---|---|
| 稳定业务租户编号、启用状态、获准身份来源和主体映射 | RF | 本地Principal/Scope已有；完整租户配置及外部身份映射仍需实现 |
| 认证成功但未绑定业务租户时拒绝；请求自报编号不能扩大范围 | RF | 接入适配与拒绝原因契约需要按V1.3落实 |
| 同租户共享按资源及操作授权，读取许可不等于删除许可 | RF、B、A | 本地Grant已有部分验证；共享候选发现和完整接入验收仍需补齐 |
| 停用、撤权约束新请求、后台执行、最终提交及旧结果获取 | RF、B、A、C | 现有授权复核继续复用；租户停用链路仍需接通 |
| 恢复旧配置或数据不能复活失效租户和许可 | RF及三流程 | 补配置版本、防复活规则和恢复验收；不从旧测试推断已经完成 |
| 区分外部身份撤权和本地撤权，确认传播方式与最大生效时间 | RF及部署接入方 | 真实身份平台联调和时限确认待办 |
| 两租户、同租户双Agent连续验收及真实P2隔离 | RF协调B/A/C | Mock展示行为，真实联合验收尚未完成 |

## 开发与验证的采用规则

新增需求追踪见[当前基线登记](../../AgentJYS-main/contracts/p3/prd-baseline.yaml)，包含V1.3原件摘要、原文段落与V13-TEN-01～06增量、责任和验证边界。

既有 `docs/p3/acceptance/requirements.yaml` 和 `source-manifest.yaml` 保存V1.2原文位置与追踪证据，明确作为历史索引保留；不能只改版本号冒充已完成V1.3全量重映射。当前使用时必须合并本次增量，后续再统一重建逐项追踪表。

此前408项测试及真实模型实验继续证明各自已验证能力，不自动证明V1.3租户接入验收完成。主ADR保持Proposed；现有Mock保持模拟标识。

指标门禁暂缓、先搭建系统的工作优先级不变；V1.3保留的产品验收要求没有删除。后续新增代码和文档不得再将V1.3视为本轮之外的可选补充。
