# P3 向 P2 接口清单

V2.0 · 2026-09-29 · 接口需求稿

类型：`string` 字符串；`bytes` 二进制；`bool` 布尔；`uint64` 非负整数；`int32` 有符号整数；`float64` 有限数值；`datetime` 为 UTC RFC 3339 时间；`T[]` 为数组；`T?` 表示值可为 null。表中字段均须出现，可空字段未知时填 null。方法名、类型及枚举为本版对接定义。

所有接口输入均携带 `CallContext`，输出均携带 `ResponseContext`；下表仅列业务体字段。调用失败时业务结果可为 null，错误放在 `ResponseContext.error`。

## 一、Remember：正文管理

正文读取由 Remember、Recall 共用；加工产物复用正文写入。

### 1.1 正文写入｜BP2-01 / BP2-04

| `idempotency_key` | `string` | 是 | 稳定幂等键；同键异载荷冲突 |
| `request_fingerprint` | `Digest` | 是 | 规范写入请求摘要 |
| `resource_ref` | `string` | 是 | 获准存储资源 |
| `scope` | `Scope` | 是 | 写入范围 |
| `target_object_ref` | `string?` | 是 | 预分配对象引用；未分配填 null |
| `payload` | `bytes` | 是 | 实际正文 |
| `expected_hash` | `Digest` | 是 | 正文全文摘要 |
| `expected_bytes` | `uint64` | 是 | 实际正文长度 |
| `media_type` | `string` | 是 | 媒体类型 |
| `encoding` | `string` | 是 | 正文编码 |
| `precondition_ref` | `string?` | 是 | 防覆盖或版本条件 |

**ContentMutationResult**

| 字段 | 类型 | 必填 | 含义 / 取值 |
|---|---|---|---|
| `operation_kind` | `string` | 是 | put / delete |
| `client_operation_ref` | `string` | 是 | 原操作 ID |
| `idempotency_key` | `string` | 是 | 原幂等键 |
| `request_fingerprint` | `Digest?` | 是 | 已关联的原请求摘要 |
| `provider_operation_ref` | `string?` | 是 | 远端操作 ID |

| `evidence` | `Evidence[]` | 是 | 原操作及结果证据 |

完成：原操作、对象版本、字节和摘要一致，且 durable/readable 达到约定；accepted 不表示完成。
