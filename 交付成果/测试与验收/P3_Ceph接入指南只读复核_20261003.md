## P3 真实接入仍需完成

1. 核实或配置实际 S3 HTTPS 入口、域名与证书链；私有 CA 须挂载给 P3 并保留证书与服务名校验。指南中的 `https://20.191.146.177:8443` 是 Dashboard 管理入口，不能充当 S3 Endpoint。
2. 明确 P3 可用的专用 bucket 或已授权对象范围，以及所需的 Get/Put/Delete/Range 权限；本次未将既有测试 bucket 自动分配给 P3。
3. 将凭据通过 Secret 或受控环境文件注入，完成 AKS 实际网络连接验证和条件写、幂等、完整读回、范围读取、删除及恢复验证。
4. 在准确候选版本上完成真实 Ceph 与 PG/Redis/Milvus/Temporal/P3/P4 的共同业务验收。公网认证成功不等于该最终验收已通过。

现有 S3 用户认证已能使用，不必先取得 Ceph VM 管理权限才能消费已授权的对象接口。新增用户、授权 bucket、调整服务及配置证书仍需对应管理员权限。
