# Agent 与 Budibase 管理 UI 验收记录

日期：2026-10-05。结论：**已提供可运行、可操作的两套本机 UI，可开展用户体验验收；完整产品替换尚未完成。**

## 可用入口与范围

| 入口 | 当前实现 |
|---|---|
| [Agent 用户平台](http://localhost:19010/) | 中文账号登录、个人会话列表、新建、搜索、聊天、当前会话上下文、重命名、归档、失败重试、来源与记忆面板 |
| [Budibase 管理中心](http://localhost:19000/app/default%20workspace/aether-admin) | 原生用户表格、租户目录、变更记录、点击用户回填表单、显示名称维护、停用确认及服务端权限校验 |

Agent 使用真实 LLM 回复和本机 PostgreSQL 持久化会话，没有注入固定回答。普通用户不填写、不选择租户。管理员与普通用户共用 Keycloak 身份和平台账号目录；Budibase 只承担页面与 REST 接入。

管理中心使用 Budibase v3.47.0 开源自托管版，业务管理员仅获 BASIC 应用访问权限，没有设计器权限。平台管理员看到全部三个租户；租户管理员的范围由平台后端确定。

## 身份接入结论

已实际验证 Budibase 原生 REST 查询可以从服务端当前用户上下文携带签名 OIDC 令牌。管理后端验证签名、issuer、audience、azp、有效期、实时 introspection，再查权威业务目录；不信任前端 tenant/role/email 参数。该路径替代了管理页面原先拟采用的短期委托桥接，原有桥接验证代码仍保留，未作为当前管理 UI 的授权捷径。

官方源码依据：[v3.47.0 查询上下文](https://github.com/Budibase/budibase/blob/v3.47.0/packages/server/src/api/controllers/query/index.ts)、[REST 集成](https://github.com/Budibase/budibase/blob/v3.47.0/packages/server/src/integrations/rest.ts)。结论以固定版本与本次真实请求为边界，不外推为所有低代码平台或所有版本均具备此能力。

本机 REST 目标为固定 Docker 宿主地址。只在此隔离环境为该 IPv4 配置访问例外，其他默认禁止的内网和元数据网段保留。发布期间触发的登录频率限制按正常窗口等待恢复，没有清除计数或关闭限流；发布脚本随后复用本机私有会话减少重复登录。

## 用户体验验收顺序

先用 `user_a` 检查 Agent 聊天，再用 `platform_admin` 和 `tenant_admin_a` 对比后台数据范围。账号密码查看、启动命令、切换账号说明见 [测试包使用说明](Agent平台测试包_20261005/使用说明.md)。请把“界面是否符合预期”和“完整功能是否已接通”分别判定，以上缺口不得标记为验收通过。

## 消息布局与文本附件增量

用户消息气泡及头像已靠右，Agent 回复保持靠左。输入框新增“添加文件”，支持 UTF-8 TXT、Markdown、CSV 的实际文本读取、待发送文件名/大小、移除、随消息发送。沿用现有鉴权聊天 API 和 12000 字符后端上限，不另建公共上传端点或文件下载接口。

验证：3 项附件测试（文本合并、非法/空/过大/二进制拒绝、数量和合计长度）与 2 项原发送恢复测试共 5 项通过；构建通过。浏览器选择测试文件并发送后，真实模型准确返回文件中的项目代号“青鸟”和交付时间“周五下午三点”。重新选择并移除后附件数为 0，空消息发送按钮禁用。390px 窄屏页面宽度为 390px，无横向溢出，用户行采用右侧排列。

边界：当前读取附件文本并随会话保存，不保存可下载的原文件；没有 PDF/Word/图片解析或 P3 文件入库。暂存附件在刷新、新建、切换会话后清除。文件每个 100 KB、最多 3 个，单文件文本 11000 字符、问题与附件合计 12000 字符。

## 退出登录修复

本次浏览器复现中旧按钮能够最终退出，未复现完全无法退出；已确认旧入口仅图标、等待身份服务期间没有反馈、过期会话返回401。现提供可见文字按钮和退出中状态；退出成功后重新加载登录页并清除本地会话及登录尝试Cookie；无会话退出幂等，仍要求可信Origin；有效会话仍校验CSRF。身份服务注销未确认时显示独立提示。3项退出相关测试通过，Ruff与前端构建通过；浏览器登录后点击退出，看到“正在退出登录”，随后“已退出当前账号”，刷新后仍处于未登录页面。此验证不等于其他应用的单点注销验收。
