# 租户与身份接入测试及回归方案

日期：2026-09-19。状态：方案待评审，以下新增用例均为 **not_run**。依据 [PRD-ADD-07](../PRD版本/PRD补充_租户与身份接入.md)、[ADR D07](../ADR版本/ADR-P2P3-001_总体架构决策.md#d07)及 EP-P3-06。本方案明确回归范围，不覆盖或改写[已有执行证据](TCR当前证据.md)。

## 环境与数据

固定业务租户 A/B、A 的两个 Agent A1/A2、B 的 Agent B1；A1 保存私有预算和会议记录，A2 初始无共享许可。准备读取许可、无删除许可、已撤销许可、获准外部身份、未绑定身份和无效凭证。使用非敏感样例数据。

三种证据分别记录：本地替身验证业务规则；真实 Entra 接入验证身份和映射；真实 P2/P3 联合环境验证存储、检索、任务及结果隔离。测试记录包含候选版本、配置版本、身份方式、数据集和实际依赖，不保存令牌或密钥原文。

## 用例

| ID / 关联条款 | 操作 | 预期断言 |
|---|---|---|
| TC-TEN-01 / TEN-01 | 用获准身份取得面向 P3 的凭证，调用保存和查询；再用已认证但未绑定业务租户的身份调用 | 获准身份映射正确；未绑定身份拒绝，不自动开通业务租户 |
| TC-TEN-02 / TEN-01/08 | 分别提交签名无效、过期、错误签发者、错误接收对象或错误凭证类型；模拟不能可靠验证身份 | 受影响请求拒绝，无业务写入或越权结果；已有效的独立路径按既定策略处理 |
| TC-TEN-03 / TEN-02/03 | A1 改写请求范围为 B，或 B1 直接提供 A 的记忆、任务、结果编号 | 不扩大授权；读取和修改被拒绝，无跨租户正文或敏感状态泄露 |
| TC-TEN-04 / TEN-04/05 | A2 先读 A1 私有记忆，再授予限定读取许可，之后尝试删除及读取许可之外的资源 | 未授权时拒绝；允许范围内可读；删除及范围外读取仍拒绝 |
| TC-TEN-05 / TEN-06 | A2 获得 Context 后撤销共享；分别在候选筛选后、最终交付前和旧结果再取前触发撤权 | 后续提交/获取使用当前许可，不交付已经无权获得的正文 |
| TC-TEN-06 / TEN-06/07 | 创建后台加工与调度待办，在执行前停用租户或主体；重启并尝试恢复旧配置 | 不沿用失效授权提交结果；已有副作用如实跟踪；配置恢复不复活旧授权 |
| TC-TEN-07 / TEN-03/07 | 在真实 P2 上为 A/B 写入高相似度内容，分别查询、精确读取、查看关系及执行受控动作；以服务身份运行后台任务 | 每条路径遵守业务范围；共享服务凭证不赋予所有租户业务权限；P3 最终结果无跨界内容 |
| TC-TEN-08 / TEN-06/08 | 在真实身份平台撤销访问资格，按确认的传播机制与时间窗口重复请求；覆盖缓存、故障与恢复 | 实际生效时间满足批准约定，记录仍有效令牌的行为；不能以本地撤权测试替代外部传播验证 |

各步骤记录通过、失败、阻塞或未执行，并关联缺陷；不以“请求失败”代替核对无越权副作用。停用后的数据保留与清理按批准范围另测，不假设停用自动删除。

## 回归触发和必跑范围

| 变更 | 必跑用例 | 理由 |
|---|---|---|
| 凭证验证、身份映射或接入网关调整 | TEN-01/02/03/08 | 防止接受错误身份、映射错误或外部撤权失效 |
| Grant、租户配置、停用或权限缓存调整 | TEN-03/04/05/06/08 | 防止共享扩大、缓存沿用旧许可或配置回滚复活授权 |
| Remember/Recall、Context 缓存、来源读取调整 | TEN-03/04/05/07；现有 TC-P3-04/05/08/09 | 同时检查授权、版本、更正、删除与迟到结果 |
| Worker、事件、恢复或 Operate 调整 | TEN-05/06/07；现有 TC-P3-08/09/13 | 检查后台身份范围与恢复后的权限 |
| P2 Adapter、索引过滤或存储布局调整 | TEN-03/07；相关 TC-P2-01～04 与 TC-INT-01 | 防止底层路径绕过租户边界 |

每次相关 PR 运行可用的本地回归；真实身份或 Provider 改动在对应集成环境运行。发布候选执行全部适用 TEN 用例并复验缺陷，关联 UAT-05。环境未就绪的必验项保持阻塞，不能用模拟通过抵扣。

通过条件：所需路径无越权读取/修改、映射正确、停用撤权按约定生效，且故障恢复不扩大范围；所需真实证据齐全。任一跨租户泄漏或重大授权错误阻断发布。该方案只覆盖租户与身份主题，不能代替整个项目的回归计划。
