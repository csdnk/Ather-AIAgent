# Agent 与管理后台 UI 使用说明

这套入口已于 2026-10-05 发布到 Azure，可直接通过 HTTPS 使用，无需启动本机测试环境。Agent 使用真实账号、独立 PostgreSQL 会话数据库和已配置的真实 LLM；管理后台使用 Budibase 开源版的原生页面、表格与表单，读取同一个平台账号目录。

**整体替换尚未完成。** 新 Agent 已接入真实 P3 保存、召回、来源原文与记忆维护；管理端尚未开放租户创建维护、用户创建、重新启用、归属调整和角色分配。旧 Web 及其启动入口已于 2026-10-05 删除；P4 后端契约测试工具保留。管理功能仍未完整实现，不能把当前 UI 当作完整产品验收已通过。

- [Agent 用户平台](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/agent/)
- [Budibase 管理中心](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/app/default%20workspace/aether-admin)
- [Budibase 可视化设计器（Builder）](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/builder)：构建、编辑管理后台 UI。使用 `builder@aether-lab.invalid` 通过 Budibase 邮箱密码表单登录；密码见[账号清单中的 Builder 账号](测试账号密码_本机验收.md#budibase-可视化设计器builder账号)。登录后进入 Default workspace，找到 aether-admin 管理应用。业务管理员账号没有设计器权限；若浏览器已登录业务管理员，可用独立无痕窗口打开设计器。

云端服务已独立运行。账号密码见[测试账号清单](测试账号密码_本机验收.md)，沿用迁移前的 8 个业务账号和 Builder 账号。

[Temporal 运行页面](https://aether-p3-demo-c50c3827.southeastasia.cloudapp.azure.com/temporal/namespaces/aether-agent-20261005/workflows)需要先以 `platform_admin` 登录管理后台，再在同一浏览器打开。当前页面仅供查看。

`测试环境.ps1` 保留用于本机开发，不是云端启动步骤；本机与云端迁移后各自保存数据。

## 建议先试这三个账号

| 账号 | 身份 | 建议操作 |
|---|---|---|
| `user_a` | 普通用户，林晓 | 登录 Agent，发送问题、新建会话、重命名、刷新后重开历史 |
| `platform_admin` | 平台管理员 | 登录管理中心，查看三个租户和全部测试账号，维护普通用户资料 |
| `tenant_admin_a` | 青禾租户管理员 | 查看青禾的用户与租户信息，确认没有远帆数据 |

管理中心登录时选择 **Log in with Aether**，使用同一套测试账号。业务管理员没有 Budibase 设计器权限；开发用 builder 账号不属于业务管理员。

Agent 直接在自己的页面输入账号和密码，成功后原地进入对话。管理员账号请只在管理后台登录；普通用户请使用 Agent。两套页面分别保留登录状态和退出操作，可在同一浏览器同时以 `user_a` 使用 Agent、以 `platform_admin` 使用后台。Agent 不会清理后台 Cookie；后台退出不影响 Agent。

## Agent 可以直接验证什么

1. 在 Agent 页面直接输入 `user_a` 的账号密码，无需填写或选择租户，也不跳转到认证网站。
2. 输入“请用三条建议帮我制定今天的工作计划”，等待真实模型回复。
3. 继续提问，验证当前会话上下文。
4. 创建新会话，在左侧列表切换；修改会话名称；刷新页面后重新打开历史。
5. 打开“来源与记忆”，查看本轮实际召回内容、来源原文和保存回执。用 `user_a` 提问“霁月项目由谁负责，交付日期是哪一天？”，本次已验证回答林晓、十二月十九日。
6. 切换到 `user_a2` 或 `user_b`，不应看到 `user_a` 的会话。

消息发送失败时原消息会保留，可重试。临时查询失败会自动重试，也可点击“刷新对话”。访问令牌会在一小时内的有效登录会话中自动刷新，退出或账号变更后停止续用；一小时会话到期需要重新登录；当前云端版本尚未采用持久化共享登录会话，重启 BFF 也会使登录失效。

## 管理中心可以直接验证什么

- **用户管理：** 查看账号、显示名称、角色、租户、启停状态；使用账号、姓名、角色、租户、状态筛选；点击用户行在右侧面板修改显示名称；停用操作有确认提示。
- **租户目录：** 平台管理员查看全部三个测试租户；租户管理员仅查看自己的租户。
- **变更记录：** 显示管理操作与同步状态。“待同步”（底层 `pending`）表示身份投影尚未完成，不能理解成 Keycloak/P3 同步成功。

建议用 `user_a2` 验证显示名称修改，完成后恢复为“陈墨（测试）”。停用验证优先使用已经停用的 `disabled_user_a`；当前界面尚未开放重新启用，避免随意停用正在使用的测试账号。

租户管理员只能维护本租户普通用户，不能维护管理员、其他租户用户或平台管理员。普通用户没有管理应用入口，直接调用管理接口也会被服务端拒绝。前端提供的租户、角色字段不作为授权依据。

## 环境边界

Agent BFF、前端、Keycloak、Budibase、平台 PostgreSQL、P3 和身份投影同步均已在 Azure AKS 运行。P3 继续使用 Azure 内的 PostgreSQL、Redis、Milvus、Ceph 和 Temporal；模型调用使用已有远端供应商。关闭本机不会停止这些云端服务。本次迁移保留了 8 个用户、3 个租户、18 个原有会话和 29 条原有对话轮次。

Budibase 使用服务端当前用户的签名 OIDC 令牌调用固定管理 API。后端验证签名、颁发方、受众、客户端、有效期、实时身份状态，再按平台目录校验角色与租户。管理页面没有保存共享业务管理员密钥。

这是已迁云的单实例测试部署。完整账号生命周期、Temporal 生产持久化迁移、多实例高可用、长稳、灾备和完整产品验收仍需继续。现有 Temporal 仍使用原测试部署。

## 消息布局与文本附件（2026-10-05 更新）

用户消息显示在右侧，Agent 回复在左侧。输入框左下角“添加文件”支持 UTF-8 TXT、Markdown、CSV；每次最多 3 个，每个不超过 100 KB，单文件文本不超过 11000 字符，问题与附件合计不超过 12000 字符。选择后显示文件名、大小与“已读取，待发送”，可点击 × 移除。

点击发送后，文件名和文本会作为当前消息交给模型并随会话历史保存。这类文本随消息进入真实 P3 保存链路。PDF、Word 请使用“我的记忆 → 导入文档”；图片 OCR 暂不支持。暂存附件在刷新、切换或新建会话后清除。

## 退出登录（2026-10-05 修复）

点击左下角账号旁的“退出登录”文字按钮。手机端先打开左上角导航。点击后显示“正在退出登录”，服务端确认后回到登录页并显示“已退出当前账号”。过期会话也能退出并清除 Cookie。若连接失败则显示未确认提示，可重试；不会把未确认的请求显示成退出成功。统一身份注销未确认时会单独提示，不能据此认定管理后台等其他应用也已退出。


## P3 记忆中心

在普通用户工作空间点击“我的记忆”。当前支持：保存、检索（工作/长期/混合/自动）、长期整理、知识提炼、更正、归档、恢复、删除、重新处理、重建索引、保留策略、自动反思、来源撤销/删除；选择记忆后可查看正文、分段、来源原文和处理状态。

- “导入文档”支持 TXT、Markdown、CSV、PDF、DOCX，最大 5 MB。扫描件没有 OCR。
- “已保存”只确认数据持久化；“可检索”表示相应索引准备完成，二者不能混淆。
- 请求未确认时保留原操作编号。刷新页面后可“继续上次提交”；文档需要重新选择原文件，系统复用上传编号。
- 工作记忆检索应先打开或创建一个对话，再进入记忆中心并勾选“仅当前会话”。
- 工作记忆启用保留策略前必须确认“相关事项已完成”。归档、删除、来源撤销应先使用自己的测试资料。
- 整理、提炼、重建索引返回任务编号；可以查询任务状态，记忆详情可查看处理状态。检索不完整时界面明确提示部分结果。
- 对话自动执行召回、读取关联来源原文、调用 LLM、保存当前用户消息。更正、删除、保留策略等明确修改通过记忆中心执行；不会把模型口头回答当成这些操作的执行回执。

## 本次删除的界面

管理工作空间中转页、P3 运维控制台及其专属 `/ops-api` 适配器已删除。Agent 不显示管理中心或运维入口。P3 原生服务、维护接口、记忆功能及业务数据保留。旧 `/management` 收藏链接只兼容跳转到独立 Budibase 地址，不参与登录或清理任何 Cookie。
