# 测试范围与待确认事项

## 本轮范围

| 能力 | 用例设计 | 执行条件/限制 |
|---|---|---|
| RF 身份、事务、任务、事件、日志、健康 | 可编写 | 已有本地实现；本地凭据身份不等于 Azure 身份平台 |
| RF 等待/断点/心跳、处置规则、配置、备份恢复 | 可编写 | 可在隔离环境及注册测试回调后执行；备份仅 RF SQLite |
| HTTP 鉴权、保存、Recall、查询 | 可编写 | 先准备身份及运行环境；API 路由见接入说明 |
| Remember/Recall/Operate 既有基础链路 | 可编写 | 可执行本地基础范围；真实模型与 lexical 结果分开记录 |
| 多块发布、记忆候选聚合、完整正文/关系组组包、地址交接 | 可先按设计编写 | 新业务接口未全部接入；标记待实现，不记为已通过 |
| Azure、真实 Milvus、真实 P2/生产介质、多副本 | 可先设计 | 等待相应接入和目标服务；本地替身不算真实联调 |
| 召回质量、性能、72 小时稳定性 | 可制定方案 | 数据集、目标环境、负载、指标口径须登记；本轮未验证 |

## 提测前逐项落实

| 编号 | 待确认事项 | 谁提供 | 如何关闭 |
|---|---|---|---|
| Q01 | 测试版本、部署地址、操作系统、数据库、模型与依赖版本 | 开发/部署 | 填环境表，保留版本证据 |
| Q02 | 两租户、同租户双 Agent、普通用户及运维主体的权限矩阵 | RF/测试 | 凭据安全交接；完成允许/拒绝示例 |
| Q03 | 数据种子、重置方法及异常注入入口 | RF/B/A/C | 正常种子可重建；断网、撤权、过期、重启可复现 |
| Q04 | 多来源故障仍有可信内容时的降级；某冲突组不完整但其他组可用时的行为 | 产品/A/B | 对照一致性检查 F01/F02，确认适用规则及返回状态 |
| Q05 | 合格压缩表示的适用范围、来源选择、调度与配置约束 | 产品/B/A/C/RF | 对照一致性检查其余条目，明确本轮范围及预期 |
| Q06 | 新增多块与全文组包接口何时接入可测版本 | B/A/C | 给出实现提交、调用入口和数据夹具 |
| Q07 | 性能阈值、稳定性负载、召回评测集和判定口径 | 产品/测试/部署 | 引用 PRD 原要求；未明部分评审，不自行填写达标数字 |

RF 已实现的本地测试不必等待所有生产环境问题关闭；仅将受具体问题影响的用例标为“阻塞”，并关联对应编号。

## 推荐第一批用例

1. 鉴权拒绝、租户隔离、越权查询日志/任务、执行中撤权。
2. 保存与 Ready 分离、重复请求幂等、同操作 ID 异内容拒绝。
3. 任务领取/续租/过期、旧租约提交拒绝、断点与业务结果一起回滚。
4. 健康证据过期/配置变化失效、健康查询不触发维护。
5. 处置连续次数、去重、冷却、维护成功但业务复验未通过。
6. 备份/恢复隔离、普通主体拒绝全库操作、在线库不被覆盖。
7. Working Recall 冒烟、版本更正与删除后旧结果失效。
