## 获取并核对代码

开发人员先给测试人员 GitHub 私有仓库读取权限。使用独立测试检出目录：

```text
git clone https://github.com/csdnk/Ather-AIAgent.git
cd Ather-AIAgent
git checkout --detach e520c9792498f6a85200097319174d48f5468f76
cd AgentJYS-main
```

在项目外创建 Python 3.13 虚拟环境并使用其 Python；业务运行前设置 PYTHONPATH 为该检出的 AgentJYS-main/src。运行目录、临时目录和日志目录也放项目外。

```text
python -m pip install -r scripts/p3/requirements-collaboration.txt
python scripts/p3/validate_collaboration.py --report <项目外目录>/collaboration.json
```

尖括号内容必须替换为已创建的实际路径。依赖安装和门禁在完整业务代码目录执行，本资料包本身不是可执行项目。建议把 TEMP/TMP、PYTHONDONTWRITEBYTECODE 及测试缓存配置到隔离工作区；依赖、模型下载按测试环境登记。

## 启动 HTTP / 进行人工测试

按[RF 接入说明](08_RF运行服务与HTTP接入.md)启动。先按[身份登记说明](04_公共底座首批实现与运行.md)配置主体及凭据摘要。该文件是历史实现说明，其中“无 HTTP”等状态以新版 RF 接入说明为准。

服务不预置默认账号。`/p3/live` 可用于进程探活，其余鉴权行为参考 HTTP 样例；任务等端点所需权限按当前身份登记。健康检查通过不代表生产验收完成。自动化源码里的 alice/bob 是隔离夹具用的测试值，不能直接用作部署密码。
