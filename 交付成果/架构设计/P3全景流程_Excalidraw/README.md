## 关键边界

1. chunk 用于匹配；Top K 按记忆 ID 计数；完整 Memory 或必需冲突组用于装包。旧版本、未发布索引批次不参与合格候选评分。
2. 主候选 K 不等于最终包内条目数。关系补全成员和 Working 单独计数，全部计入正文预算。
3. 本版读完整正文，不把命中块当作全文；预算放不下则整组跳过，不静默截断或改用摘要。必需冲突组无法完整核验/读取时不可用。
4. 不足 K 补取受候选、次数和期限限制；正常空、权限阻断、故障、额度受限及预算不足分别表达。
5. 仅 Working 直接读取，不调用 Embedding/Milvus，不做 RRF，也不自动改查长期。多来源 RRF 在记忆层执行。
6. 最终核验覆盖全部入包成员及关系修订；条件提交不能被普通“先检查、后保存”替代。历史重取仍重新核验。
7. Query 与 Passage 使用兼容模型空间；Passage 在建库时编码，不在每次 Recall 中重编码全库。Embedding tokenizer 与 ContextPack tokenizer 分开。
8. read、packed 记录真实阶段；块命中不等于正文 read，packed 不重复计热。日志不替代持久业务事实。
