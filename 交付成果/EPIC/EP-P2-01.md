# EP-P2-01 对象保存与精确读取

状态：评审稿。需求：E2。结果责任角色：P2对象。Gate：G1/G2 设计与原型评审；G3 核心可运行；G4 集成/质量；G5 用户与发布验收。

## Story

P3 希望保存的正文可以按确定版本准确读取并在崩溃后恢复。

## Prototype

打开 [P201 原型](../原型Mock/p2.html#scenario=P201)。调用方可查看输入、逐步执行与输出/失败原因。所有数据是 Mock；当前实现边界见下文。
场景成功与异常均按步骤展示，切换或重置清空模拟状态。

## Flow

Put→版本/摘要→持久落点→Head/Get→恢复核验。失败、超时或版本变化必须按 [总体流程](../架构设计/总体架构与流程.md) 处理，不能将受理当完成。

## Architecture

模块协作：E2 Object + metadata + WAL/P1。[主 ADR](../ADR版本/ADR-P2P3-001_总体架构决策.md)：D05 D08。权威数据和跨模块边界见总体架构。

## Test

具体用例：TC-P2-01。[打开前置、操作与预期结果](../测试与验收/TC目录.md)；[当前执行证据](../测试与验收/TCR当前证据.md)。
验收方法：逐项检查用例断言，附执行环境、版本、Trace/日志与结果；Mock 通过只支持行为评审，不抵扣真实系统用例。阻断缺陷修复并复验后才能申请相应 Gate。
