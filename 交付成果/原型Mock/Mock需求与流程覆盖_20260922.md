## 3 已按 PRD 明确的七处口径

当前图中的部分措辞仍需后续同步。本次 Mock 采用下列解释，未回写流程图，也未修改 PRD：

| 项目 | 本次行为 | 验证场景 |
|---|---|---|
| 来源失败 | 有独立可信内容时允许 degraded；不能无条件整次失败 | S04、S14 |
| 关系组不完整 | 排除整组，其他独立组仍可参与 | S08、S14 |
| 正文表示 | 适用路径允许合格压缩表示，明确表示类型、版本与来源 | S10 |
| 来源选择 | 显式指定与自动选择分开；仅 Working 不调用查询编码器 | S04、S13 |
| 调度触发 | 事件和周期双入口；相邻层迁移及资源约束 | S06、S12 |
| 正文位置交接 | 旧路径保留 → 目标核验 → B 引用生效 → 旧副本独立清理 | S07、S18 |
| 当前约束 | 原策略快照不越过当前权限、配置及有效性屏障 | S01、S09、S11、S19、S23 |

## 4 非功能及接入交付要求

| 章节 | 项目 | PRD 目标 | Mock/真实验收边界 |
|---|---|---|---|
| 10.1 | Working 核心读写 | P99 < 10 ms | 目标环境与负载下测量，不等于整次 Recall 延迟 |
| 10.1 | 语义计算 | ≥ 2000 条/秒 | 需真实编码计算，缓存命中不能代替 |
| FR06 / 10.1 | 内容压缩 | ≥ 5 倍且质量通过 | 同一集合实际字节；失败样本不能剔除 |
| FR13 / 10.1 | 基础策略 | 规则正确率 100%，错误降层为 0 | 需真实策略场景与执行结果 |
| FR16 / 10.1 | 预测收益 | 相对提升 ≥ 10% | 后续 P1；基础值为 0 不计算相对提升 |
| 10.7 | 持续运行 | MVP ≥ 24 小时；Final ≥ 72 小时 | 需真实环境；业务可用才算恢复 |
| 10.5–10.6 | 可靠性与扩展 | 幂等、隔离、一致性及主流程资源保障 | 模拟异常分支；真实进程、磁盘、扩容另验 |
| 11 / 12.8 | 安全与隐私 | 租户隔离、最小日志、撤权及删除 | 两租户双 Agent；真实身份/P2 另验 |
| 9 / 13 | 接入与交付 | 接口、配置、诊断、发布与恢复说明 | 不将此观察台扩展为 PRD 必需的管理产品 |
| 14.2 | 交付前业务细则 | 身份传播时限、数据/策略/运行口径 | 保留待确认项，模拟参数不冒充合同承诺 |

本次不填写真实达标值。长稳、真实吞吐、延迟、压缩质量、安全集成、物理恢复、发布包与资源竞争需要工程环境及独立证据。运行观察页的健康卡和记录数量仅是当前演示状态。

## 5 PRD 14.2 待确认细则

| 待确认事项 | 需明确的内容 | 确认时点 |
|---|---|---|
| 共享作用域 | 应用、Agent、用户、任务之间允许共享的范围 | 接入验收前 |
| 稳定事实及压缩质量 | 什么证据足以形成事实、保留内容与质量标准 | 功能验收前 |
| 事件及访问轨迹 | 事件含义、去重单位、保留周期 | 调度验收前 |
| 基础规则负载 | 场景、数据量、资源预算与正确性口径 | MVP 验收前 |
| 删除与必要记录 | 业务阻断、物理清理和必要审计记录期限 | 生产上线前 |
| 首批身份接入 | 租户、身份来源、映射规则和配置责任人 | 接入验收前 |
| 停用与撤销传播 | 本地阻断、外部通知机制与最大生效窗口 | 接入验收前 |
| 租户退出 | 数据保留、删除、恢复及不得复活授权 | 生产上线前 |

这些待确认项不取消基础调度、双事件来源或 Recall 契约。当前演示参数应写入测试前置条件；细则确认后替换参数和样例，不可将本地默认值直接视为合同承诺。
