P2 / P3 交接时，必须回答的 5 个问题

正常保存与召回

  1. 校验可信范围，保存内容与可追踪处理意图。
  2. 适用当前记忆可读，长期加工继续进行。
  3. 绑定表示、内容及版本，查询和回读通过后授予长期资格。
  4. Recall 固定来源，核验候选并在预算内组装。
  5. 最终复核资格后交付；两侧轨迹供后台调度消费。

执行结果未知时

  1. 保留原 action / migration ID 与目标版本。
  2. 原有效读取路径继续提供服务。
  3. 查询原动作和目标实际状态，不新建冲突动作。
  4. 准确内容可读且版本仍有效时，确认状态更新。
  5. 若内容已更正或删除，隔离旧回执，不重新激活。
